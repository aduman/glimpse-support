Sample markdown files

Download these .md files to try every Glimpse feature: formatting, syntax highlighting, tables, math, diagrams, presentation mode, and export. This page is permanent and will remain available for future App Store reviews.

Individual files

Right-click and choose "Download Linked File" to save any file, then open it in Glimpse with File > Open, or drag it onto the Glimpse window.

welcome-to-glimpse.md

The introductory document. Covers formatting, code, tables, math, a diagram, and the keyboard shortcuts. This same file ships inside the app and can be opened at any time from File > Open Sample Document.

feature-tour.md

The exhaustive one. Every supported construct in a single file: nested lists, task lists, nested blockquotes, four code languages, aligned tables, inline and display math, and two Mermaid diagrams.

project-readme.md

A realistic software README with badges, install steps, an API reference table, and an architecture diagram. Representative of everyday use.

release-notes.md

A short changelog with several top-level headings. Best file for trying Presentation Mode (Cmd+Shift+P), where each heading becomes a slide.

No download required

Glimpse ships with a sample document built in. Launch the app and click View Sample on the welcome screen, or choose File > Open Sample Document from the menu bar at any time. Nothing needs to be downloaded to evaluate the app.
